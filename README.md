# ミクちゃん（Windows 版）

Mac 版のミクちゃんを、Windows で動くように作り直したものです（Python）。
Mac 版のフォルダ（81_AiAssistence）とは別で、Mac 版には一切影響しません。

## はじめかた（Windows）

0. **ダウンロード**：このページの緑の「**Code**」→「**Download ZIP**」→ 好きな場所に展開
1. **Python を入れる**：https://www.python.org/downloads/ から最新の Python をインストール
   （最初の画面で「Add python.exe to PATH」にチェック）
2. このフォルダを Windows に置いて、**`セットアップ.bat`** をダブルクリック（最初の1回だけ）
3. **`ミクを起動.pyw`** をダブルクリック → 画面の右下にミクが出ます
4. ミクを**右クリック →「設定」→「AI の API キー…」**に、Google AI Studio（https://aistudio.google.com/apikey）で作ったキーを貼り付け
5. （使うなら）**右クリック →「設定」→「Gmail を登録…」**：メールアドレスと、アプリパスワード（16文字）

### Python がない PC でも動かしたいとき
`exe作成.bat` をダブルクリック → `dist\MikuAssistant\MikuAssistant.exe` ができます。
フォルダごとコピーすれば、ほかの PC でも動きます。

### Windows の起動と一緒に出したいとき
`Win + R` →「`shell:startup`」→ 開いたフォルダに `ミクを起動.pyw`（または exe）の**ショートカット**を置く。

## 使い方

- **ミクをクリック** → 入力欄が出るので、話しかけて Enter
- **右クリック** → 情報・秘書・頭脳・設定のメニュー
- ドラッグで好きな場所に動かせます。トレイ（右下のアイコン）からも出せます

| できること | 話しかけ方の例 |
|---|---|
| 天気・ニュース・電車・イベント | 明日の天気は？／ニュース／電車／週末のイベント |
| PC の状態（見るだけ） | PC の状態は？ |
| 朝のまとめ・夕方の報告 | 朝のまとめ／今日の報告（決まった時刻にも自動で） |
| ToDo | 資料作りをToDoに追加／ToDoを教えて／資料作り終わった |
| アラーム | 10分後にアラーム／15時に会議って教えて |
| Gmail の未読 | メールをチェックして |
| 頭脳 | 〇〇って覚えて／何を覚えてる？／次からは〇〇して／何を勉強した？／アイデア帳／ふりかえり |
| 服 | 冬の夜の服にして／季節の服に戻して／いつもの服にして |
| 会話 | それ以外はなんでも AI が答える（最新の情報は Google 検索で） |

## 設定

右クリック →「設定」→「設定ファイルを開く」（`%APPDATA%\MikuAssistant_Win\設定.txt`）。
Mac 版と同じ書き方です。保存すると反映されます。

- **[ミクのノート]**：頭脳（3つの層）の場所。自動なら Google ドライブ（パソコン版）の `マイドライブ\ミクのノート` を使うので、**Mac 版と同じ記憶**を共有できます
- **[飛書]**：飛書のグループの「カスタムボット」の Webhook URL を書くと、朝のまとめ・夕方の報告・ふりかえり・アラームを飛書に送ります（送るだけ）
- **[朝昼夜の時間]・[ミクの服]・[仕事の時間]**：着替えの時刻
- **[AI]** 自習の間隔、**[声]** 読み上げのオン・オフ

## Mac 版との違い

入っていないもの：
- **遠隔操作**（iMessage・スマホのページ・チャットアプリからの指示で PC を動かすこと）
- iMessage、LINE・WeChat・WhatsApp への送信、画面を読んで押す操作、見えないブラウザの操作
- アプリの通知の読み取り、Mac のカレンダー・リマインダー（ToDo とアラームは Windows 版の中にあります）
- 「へい、ミク」の声の聞き取り（読み上げはあります）

## フォルダの中身

| ファイル | 中身 |
|---|---|
| `ミクを起動.pyw` | 起動（黒い窓は出ません） |
| `miku/app.py` | ミクの窓・吹き出し・メニュー・決まった時刻の仕事 |
| `miku/commands.py` | 話しかけた言葉から機能を選ぶ |
| `miku/info.py` | 天気・ニュース・電車・イベント |
| `miku/secretary.py` | ToDo・アラーム・Gmail・PC の状態・朝夕の報告・飛書 |
| `miku/brain.py` | 頭脳 3つの層・学習・ふりかえり・自習・アイデア帳 |
| `miku/ai.py` | Gemini |
| `miku/outfit.py` | 服の着替え |
| `miku/voice.py` | 読み上げ |
| `miku/settings.py` | 設定ファイル・セリフ |
| `resources/` | ミクの画像・セリフ・設定のひな形 |
