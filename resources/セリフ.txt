# ===============================================================
#  ミクのセリフ設定
#  ・書きかえたら「再ビルド.command」をダブルクリックすると反映されます
#  ・1行に1つのセリフ。同じグループの中からランダムに1つ選ばれます
#  ・# で始まる行と空行は無視されます
#  ・[ ] の中はグループ名なので変えないでください
#    （[あいさつ 5-10] の数字は「何時から何時まで」。自由に変えたり増やしたりできます）
#  ・{時間} は「おはよう／こんにちは／こんばんは」に自動で置きかわります
# ===============================================================

# ---------- 決まった時間のひとこと ----------
# 書き方： [定時 曜日 開始-終了 ○分おき]
#   曜日：平日／毎日／土日／月水金 のように曜日を並べる
#   時間：08:45-09:00 のように24時間で書く（0845-0900 でもOK）
# 祝日は判定しないので、平日として扱われます
